# PersonalFinance

Aplicación personal para la gestión de mi economía.

## Stack

- Python
- Django
- PostgreSQL (Neon)
- Bootstrap
- HTMX
- Render

## Funcionalidades

- Dashboard financiero
- Gestión de cuentas bancarias
- Presupuesto diario
- Gastos fijos
- Balances mensuales
- Evolución del patrimonio
- Importación desde Excel
- Sincronización bancaria (futuro)
